# Yoginee - Sacred Vedic Astrology & Energy Bracelets Storefront

A high-performance Next.js 14 e-commerce storefront for **Yoginee** selling Govt. Lab Certified Gemstones, Original Nepal Rudraksha Malas, Consecrated 3D Yantras, and Energy Bracelets.

## Features
- **Royal Dark Purple & Vedic Gold Design System**: Tailored to match `yoginee-logo.png` & banner assets.
- **Zodiac (Rashi) Horoscope Widget**: Interactive daily guidance & gemstone recommendations.
- **Free Janam Kundli Calculator**: Instant birth chart calculation tool.
- **1-on-1 Astrologer Consultations**: Direct booking for Vedic Astrology, Palmistry & Healing sessions.
- **Complete Bracelet Catalog**: Gemstones, Zodiac, Navgraha, Protection, Abundance, Chakras, Rudraksha, Love, Intention, and Premium categories.

## Tech Stack
- Next.js 14 (App Router)
- React 18 & TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons
- Razorpay Payment Integration
